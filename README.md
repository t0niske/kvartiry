# DOGMA — 3D-витрина квартир

Сайт для показа квартир клиенту: выбор ЖК → 3D-квартал → квартира в 3D с отделкой, прогулкой, экскурсией, видом из окна, подборкой, сравнением и КП-картинкой.

Открыть: https://t0niske.github.io/kvartiry/

## Структура
- `index.html` — разметка страниц
- `css/style.css` — стили
- `js/01-config.js` — **настройки**: ЖК, корпуса, цены, отделка, ипотека, планировки
- `js/02…10-*.js` — утилиты, текстуры, мебель, квартира, квартал, прогулка, приложение, инструменты менеджера, мобильные панели
- `vendor/` — three.js r128, OrbitControls, RectAreaLightUniformsLib, GSAP 3.12.5

Сборки нет: файлы подключаются напрямую. Скрипты грузятся с `defer`, запуск — по `DOMContentLoaded`.

## Один файл для отправки
`python3 tools/build-single.py` → `dist/dogma.html` (работает офлайн, двойным щелчком).

## Облегчённая графика
Добавьте `?lite` к адресу — для слабых видеокарт.
