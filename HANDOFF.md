# Передача контекста: сайт DOGMA (3D-витрина квартир)

## Что это
Демо-сайт для родственницы-риелтора: показывать клиентам квартиры в ЖК застройщика DOGMA (Краснодар).
- Репозиторий: `t0niske/kvartiry`, ветка `main` — изменения можно пушить сразу, без подтверждения.
- Сайт: https://t0niske.github.io/kvartiry/ (GitHub Pages из `main`).
- Локальная копия у пользователя: `C:\Users\anton\Documents\dogma-site\` (старая однофайловая версия).
- Источник данных: https://dogma.ru (страницы /projects/record2, /samolet7, /reeds, /park-pobedy3 — рендеры, генпланы, фото двора).

## Структура
- `index.html`, `css/style.css`
- `js/01-config.js` — ЖК, корпуса (координаты по генпланам), стили фасадов, цены, отделки, ипотека, планировки
- `js/03-textures.js` процедурные текстуры · `04-furniture.js` мебель · `05-apartment.js` 3D-квартира, солнце/инсоляция
- `js/06-complex.js` 3D-квартал (кирпич, лоджии, LED, двор, школа, храм…) · `07-walk.js` прогулка
- `js/08-main.js` экраны и переходы · `09-tools.js` подборка, сравнение, экскурсия, КП · `10-sheet.js` мобильные панели-шторки
- `vendor/` three.js r128, OrbitControls, RectAreaLightUniformsLib, GSAP 3.12.5 (без CDN)
- `tools/build-single.py` → `dist/dogma.html` (офлайн один файл)

## Что уже умеет сайт
Главная (хиро, карточки ЖК с фото dogma.ru, отделки, ипотечный калькулятор, контакты) → 3D-квартал (фильтры, статусы на фасаде, шахматка, вечерний режим, облёт, метки инфраструктуры) → квартира (3 отделки с пересчётом цены, 3D/прогулка/план/вид из окна, экскурсия, ползунок солнца, ипотека, ♥ подборка, сравнение, КП-картинка). Мобильная версия со свайп-шторками. Режим `?lite` для слабых GPU.

## Важные нюансы
- На ПК пользователя (toniske-msi) WebGL в Chrome был отключён на уровне GPU (GL_VENDOR = Disabled) — не баг сайта; советовали chrome://restart, драйверы. На телефоне сайт работает.
- Тестировать можно headless Chromium в облаке (`/opt/pw-browsers`, флаги `--use-angle=swiftshader --enable-unsafe-swiftshader`, `gsap.ticker.lagSmoothing(0)`), CDN/интернет там закрыты — vendor-файлы локальные.
- Higgsfield пользователь использовать НЕ хочет.
