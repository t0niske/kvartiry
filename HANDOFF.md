# Передача контекста: сайт DOGMA (3D-витрина квартир)

## Что это
Демо-сайт для родственницы-риелтора: показывать клиентам квартиры в ЖК застройщика DOGMA (Краснодар).
- Репозиторий: `t0niske/kvartiry`, ветка `main` — изменения можно пушить сразу, без подтверждения.
- Сайт: https://t0niske.github.io/kvartiry/ (GitHub Pages из `main`).
- Локальная копия у пользователя: `C:\Users\anton\Documents\dogma-site\` (старая однофайловая версия).
- Источник данных: https://dogma.ru (страницы /projects/record2, /samolet7, /reeds, /park-pobedy3 — рендеры, генпланы, фото двора).

## Структура
- `index.html`, `css/style.css`
- `js/01-config.js` — ЖК, корпуса (координаты по генпланам), стили фасадов, цены, отделки, ипотека, планировки
- `js/03-textures.js` процедурные текстуры · `04-furniture.js` мебель · `05-apartment.js` 3D-квартира, солнце/инсоляция
- `js/06-complex.js` 3D-квартал (кирпич, лоджии, LED, двор, школа, храм…) · `07-walk.js` прогулка
- `js/08-main.js` экраны и переходы · `09-tools.js` подборка, сравнение, экскурсия, КП · `10-sheet.js` мобильные панели-шторки
- `vendor/` three.js r128, OrbitControls, RectAreaLightUniformsLib, GSAP 3.12.5 (без CDN)
- `tools/build-single.py` → `dist/dogma.html` (офлайн один файл)

## Что уже умеет сайт
Главная (хиро, карточки ЖК с фото dogma.ru, отделки, ипотечный калькулятор, контакты) → 3D-квартал (фильтры, статусы на фасаде, шахматка, вечерний режим, облёт, метки инфраструктуры) → квартира (3 отделки с пересчётом цены, 3D/прогулка/план/вид из окна, экскурсия, ползунок солнца, ипотека, ♥ подборка, сравнение, КП-картинка). Мобильная версия со свайп-шторками. Режим `?lite` для слабых GPU.

## Важные нюансы
- На ПК пользователя (toniske-msi) WebGL в Chrome был отключён на уровне GPU (GL_VENDOR = Disabled) — не баг сайта; советовали chrome://restart, драйверы. На телефоне сайт работает.
- Тестировать можно headless Chromium в облаке (`/opt/pw-browsers`, флаги `--use-angle=swiftshader --enable-unsafe-swiftshader`, `gsap.ticker.lagSmoothing(0)`), CDN/интернет там закрыты — vendor-файлы локальные.
- Higgsfield пользователь использовать НЕ хочет.

## Визуализации v2 (25.10.2026, сессия на ПК пользователя) — подробности в `tools/blender/README.md`
- **Референсы**: официальные визуализации и генпланы со страниц dogma.ru (блок `galleryData` в HTML, ~55 картинок). По ним сверены объёмы, этажность, кирпич, рамы, балконы, короны башен; цвета фасадов в `js/01-config.js` (`STYLES`) тоже поправлены под них.
- **Blender 5.2.3** (без дискретной GPU, Intel Core 5 120U): сцены собираются скриптами в фоне — `blender -b --factory-startup -P tools/blender/run.py -- cx_rekord <папка> final`; Cycles, ~2 мин на экстерьер, ~7–12 мин на интерьер 1600×900. Blender MCP годится для мелочей, но длинные вызовы (>2 мин) у него отваливаются, и в файле пользователя открыта его сцена AUA_hero — её не трогать.
- **Модели**: 4 квартала по генпланам (окна-проёмы с рамами, отливы, французские балконы, балконы, витражи, эркеры, кровельное оборудование; дороги, парковки, машины, деревья, кусты, клумбы, площадки, фон города) и евродвушка `TPL[2]` в 3 отделках со всеми комнатами (окна ПВХ с ручками, радиаторы, розетки, двери, ламинат/ёлочка досками, сантехника, кухня с техникой, мебель, шторы, книги, растения, свет).
- **Codex** (`tools/blender/codex2.ps1`): рендер Blender (композиция — главное) + официальная визуализация того же ЖК (материалы) → фото. `gen_codex.ps1` — копия скрипта скилла с исправлением для PowerShell 5.1 (у скилла с `-Image` падение на stderr codex).
- Картинки: `img/renders/{rekord|samolet7|reed|park3}_{aerial|yard|street}-{800|1600}.webp`, `img/interior/{rough|dev|turn}_{living|bed|bath|hall}-{800|1600}.webp`; на странице грузятся лениво, в `?lite` только 800 px. Офлайн-файл `dist/dogma.html` берёт картинки с GitHub Pages.
- На сайте (`js/11-gallery.js`): секция «Визуализации» (табы по ЖК, 3 ракурса), фото в карточках отделок, кнопка «Фото фасадов и двора» в панели ЖК, «Фото отделки» в панели квартиры (миниатюра меняется с отделкой), общий лайтбокс (стрелки, свайп, Esc, табы).
- Подписи честно говорят, что это демо-визуализации, не официальные материалы застройщика. GLB не делали: 3D на сайте процедурный (three.js), тяжёлые модели ухудшили бы `?lite`.
