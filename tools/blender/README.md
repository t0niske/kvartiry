# Визуализации DOGMA: Blender + Codex (v2)

Как получены картинки в `img/renders` (4 ЖК × с высоты / двор / улица) и `img/interior` (3 отделки × кухня-гостиная / спальня / санузел / прихожая).

## 1. Референсы
Официальные визуализации и генпланы взяты со страниц проектов dogma.ru (`/projects/record2`, `/samolet7`, `/reeds`, `/park-pobedy3`: блок `galleryData` в HTML, картинки `storage.yandexcloud.net/t2v-storage/images/<key>/w1200.webp`). По ним сверены объёмы, этажность, материалы и детали:
- **Рекорд 2** — терракотовый клинкер, графитовые рамы, скошенные углы с остеклёнными эркерами, витражные «полосы» на всю высоту, французские балконы, кирпичные надстройки на кровле; рядом храм, школа со стадионом, ж/д.
- **Самолёт 7** — башни из графитового кирпича с золотыми порталами на 2 этажа, золотые эркеры и «корона»; секции из светло-серого кирпича с коричневыми панелями и белые с оранжевыми лоджиями; два двора, ручей.
- **РИДЗ** — башни разного кирпича (бордовый, графит, песочный, ржавый, коричневый), пилястры через 2 окна, ниши-лоджии, светлый каменный двухсветный цоколь; Кубань с камышами.
- **Парк Победы 3** — замкнутый квартал: 2 башни по 21 этажу с бронзовой короной и выносным карнизом-рамой, крылья из чередующихся серых и коричневых кирпичных секций, сад с белой аркой.

## 2. Модели (Blender 5.2, Cycles)
| файл | что делает |
|---|---|
| `dg_core.py` | быстрый сборщик мешей (`from_pydata`, ~1 млн граней за 5–8 с), PBR-материалы: кирпич с реальным размером, стекло с «интерьером» за окном, доски, плитка, мрамор, ткань, листва |
| `dg_facade.py` | фасады: настоящие проёмы с откосами, рамы с импостами, отливы, французские балконы, балконы, витражи, эркеры, парапеты, кровля с оборудованием |
| `dg_land.py`, `dg_city.py` | дороги с разметкой, тротуары, парковки, машины, деревья (ветки + листовые карточки), кусты, клумбы, площадки, корты, бассейны, фон города, частный сектор |
| `cx_rekord.py`, `cx_samolet.py`, `cx_reeds.py`, `cx_park3.py` | кварталы: раскладка по генплану, стиль фасадов, благоустройство, камеры `aerial` / `yard` / `street` |
| `apt_flat.py` | евродвушка `TPL[2]` (9,6 × 7,0 м, потолок 2,8 м) со всеми комнатами в 3 отделках: окна ПВХ со створками и ручками, радиаторы, розетки, двери с наличниками, ламинат/ёлочка досками, санузел с сантехникой, кухня с техникой, мебель со скруглениями, шторы складками, растения, книги, свет |
| `run.py` | `blender -b --factory-startup -P run.py -- <модуль> <папка> <preview|final> [камеры] [отделка]` — строит сцену, сохраняет `.blend`, рендерит |
| `final.sh` | все финальные рендеры подряд (1600×900; экстерьеры 96 сэмплов, интерьеры 150) |

## 3. Фотореализм (Codex, подписка ChatGPT)
Референсы в репозиторий не кладём (это материалы застройщика): `fetch_refs.js` + `refs_to_jpg.py` скачивают их в `refs/`.

`codex2.ps1 -Key rekord_yard` отправляет в Codex две картинки: рендер из Blender (композиция, геометрия, этажность — главное) и официальную визуализацию того же ЖК из папки `refs/` (материалы и стиль). Для интерьеров — только рендер + описание отделки. `pipeline.ps1` отправляет кадры по мере готовности рендеров. `gen_codex.ps1` — копия скрипта скилла codex-image с исправлением для PowerShell 5.1.

## 4. WebP для сайта
`to_webp.py` в Blender: `convert(photo_dir, 'img/renders', 'img/interior')` → версии 1600 и 800 px. В `?lite` сайт грузит только 800 px.

Картинки демонстрационные (не официальные материалы застройщика); `.blend`-файлы не храним в репозитории (15–50 МБ каждый) — они собираются скриптами за секунды.
